# Exact-Sum Constant Operator Fixture

This non-playable fixture proves the public Script V1/API 5 authoring surface
for `constraint.exact_sum_equals_constant`. It is not a named variant, does
not occupy a portfolio category, and cannot be promoted as a playable
reference.

The declared `2..4` distinct cells must add to the fixed target. `main.lua`
validates and normalizes the fixed declaration at startup. The Host owns
partial evaluation, candidates, conflicts, completion, notes and UI.

中文说明：这是通用 operator 的非可玩验证 fixture，不是具名变形数独，也不占用
玩法容量。声明的 `2..4` 个不同格子中的数字之和必须等于固定目标值。
